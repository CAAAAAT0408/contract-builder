# 계약서 자동작성 (공급계약서 · 추가선택품목 계약서)

이전 현장의 계약서와 새 현장의 **입주자모집공고(.hwp)** 를 넣으면,
공고에서 바뀐 내용을 반영한 새 계약서와 변경내역(.xlsx)을 만들어 주는 도구입니다.

| 탭 | 넣는 파일 | 만드는 파일 |
|---|---|---|
| 공급계약서 | 샘플 공급계약서(.docx) + 모집공고(.hwp) | 공급계약서(.docx, 바뀐 글자 형광펜) |
| 추가선택품목 계약서 | 샘플 추가선택품목 계약서(.xlsx, 타입별 시트) + 모집공고(.hwp) | 추가선택품목 계약서(.xlsx, 서식·인쇄설정 유지) |

**바로 쓰기: https://caaaaat0408.github.io/contract-builder/**

- 파일은 서버로 전송되지 않습니다. 브라우저 안에서 Python([Pyodide](https://pyodide.org))으로 처리합니다.
- 처음 열 때 10~20초 준비 시간이 걸리고, 그 뒤로는 브라우저에 저장돼 빨라집니다.
- 크롬·엣지 최신판에서 쓰세요. 인터넷이 연결돼 있어야 합니다(Pyodide를 cdn.jsdelivr.net 에서 받습니다).

## 하는 일

1. **1페이지**: 입주예정일, 약정일자(계약금·중도금), 납부계좌를 공고에서 찾아 바꿉니다.
2. **이전 현장 이름 바꾸기**: 블록번호·단지명을 계약서 전체에서 새 값으로 바꿉니다.
3. **유의사항(제○조 기타사항)**: 계약서 항목과 공고 '유의사항' 항목을 짝지어
   - 공고 내용이 바뀐 곳만 고칩니다 (계약서에서 다듬어 둔 끝맺음 표현은 유지)
   - 공고에 새로 생긴 항목을 끼워 넣습니다
   - 계약서에만 있는 문구는 '확인 필요'로 보여 줍니다 (유지/삭제 선택)
   - 동 번호가 다르면 동별 유의사항을 통째로 바꿉니다
   - 공고의 "청약 및 계약" 같은 표현은 "계약"으로 바꿉니다
4. 바뀐 글자는 계약서에 **노란 형광펜**으로 표시합니다. 검토 후 Word에서 Ctrl+A → 텍스트 강조 색 → 색 없음.

### 추가선택품목 계약서 (엑셀)

1. 타입 시트(예: 84A)마다 `1) 발코니확장 2) 시스템에어컨 3) 추가선택품목 4) 패키지` 표를 찾아,
   시스템에어컨·추가선택품목·패키지 표를 **공고에 그 타입으로 나온 줄만, 공고 순서·표기·금액대로 다시 짭니다**
   (없는 품목 줄은 지우고 새 품목은 샘플 줄을 본떠 넣음, 품목 번호·패키지 항목 번호 다시 매김).
2. 중도금 납부일(표 머리글), 납부계좌, `■ 주소 단지명` 줄을 새 공고 값으로 바꿉니다.
3. 시트를 공고 타입에 맞춥니다: 없는 타입은 비슷한 시트를 복사해 만들고, 공고에 없는 타입 시트는 지우고,
   타입마다 내용이 다른 '84A,B' 시트는 타입별로 나눕니다.
4. 공고에 발코니 확장 금액이 비어 있으면 화면에서 직접 넣습니다.
5. 엑셀 내부 XML 을 직접 고쳐서 셀 서식·글자 부분서식·인쇄설정·그림·메모가 샘플 그대로 유지됩니다.

공고 표 형식은 타입이 열인 표(구분 | 84A | 84B …, 머리글 두 줄 포함)와 타입이 줄인 표(약식표기 칸) 모두 읽습니다.

자세한 사용법은 [사용법.md](사용법.md).

## 구성

| 경로 | 내용 |
|---|---|
| `docs/` | 웹 버전 (GitHub Pages). `index.html` 화면, `worker.js` 가 Pyodide 를 띄워 `py/` 의 엔진을 실행 |
| `docs/py/engine.py` | 계약서·공고 대조, 변경안 만들기, 변경안대로 계약서 고치기 |
| `docs/py/notice.py`, `hwp_reader.py` | 한글(.hwp) 공고문 읽기 (한컴오피스 없이 직접 해석) |
| `docs/py/contract.py` | Word 계약서 읽기·고치기 (서식 유지) |
| `docs/py/report.py` | 변경내역 엑셀 |
| `docs/py/options.py` | 추가선택품목 계약서: 공고 표 읽기, 시트 구역 찾기, 공고 기준으로 표 다시 짜기, 시트 추가·삭제·나누기 |
| `docs/py/xlsxio.py` | 엑셀 내부 XML 직접 편집 (서식·리치텍스트 유지, 행 넣기·지우기, 시트 복사·삭제·이름 바꾸기, 간단한 수식 재계산) |
| `docs/py/wheels/` | olefile, openpyxl, et_xmlfile (순수 Python 휠) |
| `app/` | (선택) 사내망 서버 버전. 같은 엔진을 씁니다. `페이지 열기.bat` 으로 실행 |

## 업데이트할 때

`docs/py/*.py` 를 고친 뒤 `docs/worker.js` 와 `docs/index.html` 안의 `VERSION`(`?v=`) 값을 바꿔야
팀원 브라우저가 새 파일을 받습니다.
